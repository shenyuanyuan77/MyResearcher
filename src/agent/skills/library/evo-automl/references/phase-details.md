# Phase 详细模板与问题清单

## Phase 0：Research Qualification（研究资格评估）

不直接进入搜索。先回答四问并打分：

- Q1 有没有结构设计空间？（已有充分调优的固定结构且无预算压力 → 低分）
- Q2 是否存在人工调参成本？（专家试错数周 → 高分）
- Q3 数据是否支持搜索？（≥数千条、已固定划分、指标可复算）
- Q4 是否有明确指标？（macro-F1/准确率/mAP…不可是"看起来更好"）

输出格式：

```
NAS适用性评分: 8.5/10
理由: 多模态输入(谱图+波形) 结构选择丰富(算子/宽度/深度均开放)
      数据4849条且冻结块级划分 指标macro-F1明确
风险: 数据规模偏小 → 代理可靠性需重点审计(R3)
```

<6分停止并输出劝退说明（例：数据<500条、任务已有占优固定解、指标主观）。

## Phase 1：Evidence Collection（证据库建立）

建立 Evidence Bank，四类证据逐项登记：

| 类型 | 收集来源 | DIAT实例 |
|---|---|---|
| 数据来源 | 数据集论文、采集协议 | DIAT-μSAT原论文（9篇参考文献夹） |
| 基线证据 | 同数据集已发表方法+指标+划分口径 | RadSATNet 0.957 / MBv3S 0.931 / CVNN 0.752…（主表） |
| 零件证据 | 同模态论文的模块 + 自有历史实验 | 残差块←RadSATNet；DS卷积←MobileNet系；膨胀DS←AnyDwell自有轮次 |
| 机制证据 | 方法学顶刊（编码/算子/评价/多目标） | 14篇ENAS文献映射表（见evidence-bank.md） |

登记格式（每个零件一行，缺出处不准入空间）：

```
零件: 膨胀深度可分离块(d=2)
来源: 自有实验 DIAT-G-260908-001 (AnyDwell-B2 0.967)
作用: 不加参数扩大时频感受野，匹配旋翼谐波间隔
准入: Yes
```

## Phase 2：Objective Design（优化目标设计，最先落盘）

目标必须是可计算、可复算的表达式，三选一或组合：

```
单目标:     max metric(arch)                    s.t. params ≤ B
软约束多目标: max metric(arch) − λ·complexity(arch)
多目标:     max [F1] & min [Params, FLOPs, Latency]   → 输出帕累托前沿
```

设计问句（逐项向任务所有者确认）：
1. 主指标是什么？为什么用它（类别均衡性/任务要求）？
2. 部署预算是多少（参数量/FLOPs/延迟/显存）？硬约束还是软约束？
3. 有没有第二目标需要进fitness而不是只记录？
4. 代理评价的fitness与终审指标是否一致？（不一致会产生代理过拟合）

无人机雷达示例（DIAT实际采用）：
`max val_macro_F1(20%子集×12ep)`，硬预算 `params ≤ 600K`，
全程记录 (F1, Params, MACs) 三元组供帕累托分析。
若任务要求推理<5ms，则把延迟预测器加入目标（参照EvoXBench硬件目标）。

## Phase 3：Search Space Compiler（搜索空间编译）

**步骤0（先于一切）：从用户文献推断表示族——不预设答案。**
统计用户证据库中主流结构形态：链式堆叠CNN多 → chain_cnn；
cell重复+DAG连接（NASNet/DARTS式）→ cell_dag；树拓扑（U-Net族/跳连接丰富）
→ tree_gp；patch/token序列（ViT/谱注意力/Mamba）→ token_transformer；
主干+多分支 → hybrid。判定依据写进evidence.yaml。
表示族决定"基因能表达什么"；族内的一切（模块、维度、范围）仍来自用户证据。

把人的描述（"我的文献里主要是CNN+Attention"）编译成机器可搜索空间：

1. **从用户文献中抽取候选模块**（候选池建设procedure）：
   ① 通读用户给的文献方法节，列出反复出现且作用可陈述的功能组件；
   ② 每个组件登记：名称/出处(哪篇)/作用(为什么允许它存在)/builder接口；
   ③ 自有历史实验的组件同样登记（出处写实验日志编号）；
   ④ 无证据组件不登记；确有潜力者先做单点验证实验再准入。
2. **零件准入表（Search Space Justification Table，论文资产之一）**

| 模块 | 来源 | 作用 | 准入 |
|---|---|---|---|
| Residual Block | 同数据集文献SOTA | 稳定深层训练 | Yes |
| Depthwise Conv | MobileNet系+同数据集基线 | 参数量降一个量级 | Yes |
| Attention | 同模态Transformer论文 | 捕获长程周期依赖 | Yes（若显存允许） |
| 某未验证模块 | 无同模态证据 | — | No（先单点验证再准入） |

3. **基因编码规范**：离散段（级数/块数/算子/池化）+ 连续段（宽度[16,128]步进8，
   R4强制连续）+ 训练参数段（lr对数连续[1e-4,3e-3]、wd/dropout离散）。
   通道不一致处自动插1×1过渡（L1冒烟会暴露遗漏）。
4. **优化器抽象**：从 {GA, PSO, DE, Bayesian, Random} 选择主臂；Random 恒为对照臂（R2）。
5. 输出四个yaml（templates/），落盘后进入冒烟。

## Phase 4：Search Validation（三层冒烟，R6）

```
L1 随机基因前向:  30个随机基因构建+前向，形状/通道衔接全过
L2 代理评价:      2ep×4个体，loss下降、fitness有区分度
L3 全链路:        top-1基因 2ep全量训练→test评估→概率落盘→聚合
```
任一层失败：修复后重跑该层，三层全过才准开正式搜索。
实测教训：L1曾抓出级间过渡卷积缺失；L3曾抓出输出目录未创建。

## Phase 5：Evolutionary Search（多臂搜索）

最低两臂（等评价预算）：
- 主臂：选定优化器（GA默认：种群10×15代、锦标赛k=3、精英top-2、
  均匀/算术交叉、重采样+高斯变异p=0.3/σ=0.15；
  多目标fitness时选择机制换NSGA-II非支配排序，锦标赛仅限单目标；
  PSO臂=速度更新含个体最优+群体最优、DE臂=差分向量变异、ACO=离散组合空间）
- 对照臂：均匀随机采样同预算
可选臂（消融预案）：权重继承on/off、宽度连续/离散、不同优化器互比。

搜索日志每代落盘：`search_log.json`（best/top10/config）+ `eval_history.jsonl`（逐评价）。
监控要点：种群均值逐代走势（进化的群体效应证据）、结构模式是否收敛、
继承张量数、单评价耗时。

## Phase 6：Search Audit（代理可靠性审计，R3）

审计集 = 主臂top-10基因 **+ 3个随机中低分个体（多样性对照）**，全量单种子重训。
加对照的理由：种群收敛后top段结构同质、proxy分数跨度被压缩
（DIAT实测仅1pp），只在top段内算相关会错估保真度。

输出 Spearman ρ(proxy fitness, full test)，**分两段报告**：
全范围ρ（含对照点）与top段ρ，并附 p 值与两段分数跨度。

| ρ | 分级 | 强制策略 |
|---|---|---|
| >0.7 | High | top-3 终审 |
| 0.4~0.7 | Medium | top-5 终审 |
| <0.4 | Low | 禁止依赖代理排序：top-10 全量终审，或重新设计代理（加数据/加轮数/换指标） |

统计警示：n<15时ρ分级只是参考（n=10时ρ=0.4对应p≈0.25），分级结论必须连p值报告；
DIAT实测ρ=0.355(p=0.31)即Low档。
预算护栏：top-K×n_seeds×单次全量时长先核算，超预算降K并如实记录（不许悄悄砍种子数）。

同时输出：proxy分数跨度 vs 全量分数跨度（压缩比）、代理过拟合个案
（proxy极高但test塌陷的个体，DIAT离散臂0.994→0.930）。

## Phase 7：Final Adjudication（统计裁决）

- top-K × 3种子（默认2026/2027/2028）× 冻结test
- 报告：mean±std + 多数投票(mv)
- 配对bootstrap×2000：CI95不含零才声明显著；提升<0.5pp不予认可（用户裁决规则）
- 对照锚点：文献SOTA + 自有前SOTA + 随机臂最优，三方都要比

## Phase 8：Ablation & Paper Assets（消融与论文资产）

消融矩阵（R8最低配置）：

| 消融 | 做法 | 回答的问题 |
|---|---|---|
| 协同超参 | 同结构换默认超参×3种子 | "参数优化"贡献多大（DIAT:+1.78pp显著） |
| 随机搜索 | 对照臂最优全量×3种子 | 收益来自进化还是预算 |
| 宽度编码 | 连续vs离散臂 | 连续编码价值 |
| 权重继承 | on/off臂 | 评价加速价值 |

交付物清单：实验日志（E0复杂度/E1搜索动态/E2审计/E3主表显著性/E4消融编号）、
实验索引更新、交付报告（含故事线建议）、四件论文资产（writing-assets.md模板）。
