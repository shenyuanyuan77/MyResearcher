# MyResearcher · 运行与演示指南

## 一、启动流程

### 1.1 首次准备
```bash
# 1. Python 依赖
pip install -r requirements.txt

# 2. 前端依赖
cd frontend && npm install && cd ..

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env，至少填写 DEEPSEEK_API_KEY
```

### 1.2 启动
**Windows 一键**：双击 `start.bat`
**命令行**：`python start_all.py`

启动器会依次拉起：
1. 学术 MCP（:7001）—— 连接 CrossRef/OpenAlex/S2
2. 后端 FastAPI（:8000）—— 后台初始化 Agent（约 30-60s）
3. 前端 Vite（:3001）

### 1.3 验证
浏览器访问 http://localhost:3001，使用 `yanjiu / yanjiu123` 登录。

健康检查：http://localhost:8000/health
- `status: healthy` + `ready: true` + `mcp_academic_ok: true` = 全部就绪。

## 二、演示脚本（答辩可用）

登录后，可点击首页五大引擎快捷卡，或直接在对话框输入以下 golden prompt：

### 🧭 引擎① 方向构建
```
我想研究「大模型思维链与机器人控制结合」这个方向，请帮我做方向构建：拆解子方向、给出核心关键词、推荐检索式，并结合领域热度给出进阶研究节点建议。
```
**预期**：调用 `topic_radar`，给出领域热度趋势（OpenAlex 近3年论文数）、子方向、检索式。

### 🔍 引擎② 情报提纯
```
请检索 retrieval augmented generation（RAG）领域的最新高引文献，召回 8 篇带真实 DOI 的论文并出表，然后精读其中被引最高的 2 篇，给出创新点、方法与可引用句。
```
**预期**：`paper_search` 召回真实文献 → `write_markdown_table` 出表（含 DOI 链接）→ `paper_distill` 精读。

### 👤 引擎③ 资产透视
```
请帮我做学者资产透视：查 Jason Wei 这位学者的研究布局，给出 h 指数、代表作 Top、研究主题分布和跟进建议。
```
**预期**：`author_profile`（若 OpenAlex 无档案，Agent 会用 paper_search 反向构建并诚实说明）。

### 🧬 引擎④ 跨界启发
```
请推演「大语言模型」与「量子计算」的融合可行性：先检索已有的交叉工作（带 DOI 作佐证），再给出融合路径、可行性评估、技术路线与风险盲区。
```
**预期**：`cross_search` 召回真实交叉工作 → 主模型推演融合路径与可行性。

### 📝 引擎⑤ AI 审稿
```
请帮我审稿。我的论文摘要如下：
[粘贴摘要]
请做规范性检查、引用真实性核对、逻辑漏洞与改进建议，最后给出评分表。
```
**预期**：委派 `review-expert` 子 Agent，用 `paper_search` 核对引用真实性，出问题清单 + 评分表。

## 三、关键验证点（演示亮点）

1. **真实 DOI 溯源**：每篇文献都有可点击的 `https://doi.org/...` 链接，点击直达原文页面。
2. **零幻觉**：Agent 不编造文献；找不到时如实说明（如 OpenAlex 未收录某学者）。
3. **多源归并**：同一文献可能来自 CrossRef+OpenAlex，系统自动去重保留最全信息。
4. **会话记忆**：刷新页面或重进会话，历史保留。
5. **报告下载**：深度报告生成后回复「下载」，Agent 调 `save_report_locally` 存到桌面。

## 四、排障

| 问题 | 解决 |
|---|---|
| 启动报端口占用 | 双击 `stop.bat`，或 `netstat -ano \| findstr :8000` 找 PID 后 `taskkill /F /PID <pid>` |
| Agent 长时间未就绪 | 查 `logs/backend.log`；确认 `.env` 的 `DEEPSEEK_API_KEY` 有效 |
| 文献检索无结果 | 查 `logs/mcp.log`；确认网络可访问 `api.crossref.org` |
| MCP 降级告警 | `/health` 显示 `mcp_academic_ok: false` 时，MCP 不可用，重启 MCP 服务 |
| 前端 401 | Token 过期，重新登录；或确认后端已就绪 |
